# 🏦 Estudo de Fundamentos Visuais & Formatação: Itaú UI Style Guide

Este repositório contém a documentação e a estrutura de um protótipo de formatação e fundamentos visuais (Style Guide) desenvolvido no [Figma](https://www.figma.com/ "Figma") para fins de aprendizado de UX/UI Design. O projeto utiliza a identidade visual inspirada no banco **Itaú** para aplicar conceitos práticos de hierarquia, consistência de cores, escala tipográfica e testes de contraste.

---

## 📌 Visão Geral do Projeto

O objetivo principal deste projeto foi exercitar a padronização de interfaces digitais através da criação de um guia de estilos escalável, garantindo que o layout seja harmônico e visualmente acessível.

A estruturação abrange três pilares essenciais de uma interface:
1. **Identidade de Marca e Cores:** Mapeamento de paletas primárias, secundárias, estados de feedback e tons neutros.
2. **Tipografia e Escala de Fontes:** Definição de proporções baseadas na anatomia das fontes para títulos e parágrafos.
3. **Acessibilidade e Contraste:** Testes práticos de legibilidade aplicando as variáveis de cores sobre fundos claros e escuros.

---

## 🎨 Estrutura do Protótipo

### 1. Cores (Color Palette)
A paleta de cores foi dividida em categorias funcionais com variações de intensidade (`-1` para tons mais claros e `+1` para tons mais saturados):

*   **Primárias (Laranja característico):** `#CC4200` (Primária -1), `#EC6200` (Primária) e `#FF8E22` (Primária +1).
*   **Secundárias (Tons de Azul):** `#509AE9`, `#2079E3` e `#1060DE`.
*   **Escuros/Neutros (Dark):** `#403E3E`, `#262323` (Fundo predominantemente escuro) e `#0B0A0A`.
*   **Claros/Neutros (Light):** `#FFFFFF`, `#F2F5F7` e `#D3DDE4`.
*   **Estados (Sucesso e Perigo):** 
    *   *Success (Verde):* `#7BD38B`, `#15D05F`, `#0FC03E`
    *   *Danger (Vermelho):* `#FE2800`, `#DF1C00`, `#9F1705`

### 2. Tipografia & Font Scale
Para este estudo, foi adotada a família tipográfica **Poppins**, devido à sua excelente legibilidade em telas digitais tanto em formatos regulares quanto em variações semibold/bold.

A escala de texto (`Font Scale`) foi estruturada de forma estrita para manter o ritmo vertical do layout:
*   **H1:** 40px
*   **H2:** 34px
*   **H3:** 28px
*   **H4:** 24px
*   **H5:** 18px
*   **Parágrafo:** 16px
*   **Small:** 14px

### 3. Matriz de Contraste
Bloco dedicado ao laboratório visual de acessibilidade (regras WCAG), testando a aplicação das fontes e cores de primeiro plano em três cenários de superfícies de fundo distintos:
*   **Fundo Claro/Neutro:** Garantindo legibilidade diurna.
*   **Fundo Laranja (Marca):** Testando o comportamento dos textos sobre o tom institucional.
*   **Fundo Escuro (Dark Mode):** Validando o conforto visual e taxas de contraste para interfaces noturnas.

## 🎯 Aprendizados Adquiridos

*   **Componentização no Figma:** Prática de organização de estilos globais (Text Styles e Color Styles) para acelerar o fluxo de trabalho de design.
*   **Hierarquia Visual:** Aplicação prática da escala tipográfica para guiar o olhar do usuário de forma natural.
*   **Design Inclusivo:** Entendimento sobre a importância de validar as taxas de contraste de cores antes de avançar para as telas de alta fidelidade do produto.
